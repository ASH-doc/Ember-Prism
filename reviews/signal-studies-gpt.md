# Signal Studies preset bank

Eight original recipes per synth, appended after the existing banks. Ember emphasizes analog performance and synthesis, including acid glide, hard sync, pulse-width modulation, chord memory, ring modulation and a noise swell. Prism uses comb filtering, FM, formant motion, shimmer, pitched steps and sample-and-hold. Source patches remain in their original files and all preset and parameter IDs remain valid.

Both preset selectors now group All sounds by musical role. Sound categories filter across banks. Signal Studies and Claude Compatibility are separate bank filters with sound submenus. Search checks names, sound groups and tags. Previous and Next follow the filtered menu and retain the original underlying IDs.

The Mac Release build passed HostIntegration and ActualVST3. The new host tests validate all 16 patches and browser filtering and render the same four-second phrase through each patch. The gain-matched correlation check screens for near-identical waveform renders. These are automated checks, and an audition on the intended hardware is still useful for musical balance. Windows verification is pending. The bank is isolated on design/curated-sound-banks while Claude works on mapping.
